# 외국어 영화 자막 정확도 개선 계획

대상: 일본어 영화·드라마와 여러 사람의 대화(사용자의 추가 요청 반영). 기존 CrisperWhisper 제거와 무음 구간 억제를 유지한다.

## 구현 범위

1. 일본어 영화 설정: 일본어 고정, large-v3, GPU 정밀 연산, 한국어 번역을 한 번에 선택. 다른 외국어/자동 감지도 개별 선택 가능.
2. 음성 선택: 파일별 음성 트랙의 언어·제목·채널 수를 표시하고 명시적으로 선택. 선택한 트랙만 FFmpeg로 추출. 중앙 채널이 있는 다채널 음원은 선택적으로 중앙 대사 채널을 사용하고, 없는 파일은 일반 믹스로 안내 후 처리.
3. 인식 품질: faster-whisper의 float16 연산을 선택할 수 있게 하고 GPU 메모리 부족 시 int8_float16, 이후 CPU 순서로 복구. 사용자가 입력한 인명·지명·용어를 두 엔진의 모든 디코딩 구간에 전달. 이전 인식 결과를 다음 구간에 강제 주입하지 않으며 VAD를 우회하지 않음.
4. 번역 검증: 감지/지정한 원어를 번역기에 전달하여 짧은 대사의 잘못된 언어 추정을 줄임. 일본어의 표시용 줄바꿈은 공백 없이 연결하여 단어 훼손을 방지. 번역 전 원문 SRT를 충돌 없이 보존. 타임스탬프와 자막 수를 유지.
5. 자막 표시: 인식기가 반환한 단어 연결·문장부호를 보존하고 긴 자막을 단어 시간 경계에서 분할. 유효한 양수 길이, 최대 표시 시간과 줄 길이, 무음 경계 유지. 작업별 임시 파일을 분리.
6. 무음·효과음 억제: 기본 강도를 '강하게'로 지정. 발화 확률·인식 신뢰도·시간 배치가 부족한 결과를 제거하고, 1.2초 이하 구간 또는 단어 신뢰도가 낮은 8초 이하 구간을 같은 모델로 따로 재확인. 재확인에는 이름 힌트나 앞뒤 대사를 넣지 않으며, 일치하지 않는 불확실한 구간을 제외. 실제로 말한 특정 문구를 금지어로 삭제하지 않는다.

## 검증과 한계

- 변경 전 소스를 별도로 보존하고 동일한 영어 합성 대사, 긴 무음, 작은 목소리, 합성 배경음 샘플을 이전/새 버전으로 비교한다. 문자 오류율(CER)과 무음 침범을 측정한다.
- 다중 음성 트랙과 중앙 채널 추출은 합성 미디어 파일로 실제 FFmpeg 동작을 검사한다.
- Python/Node 회귀 테스트, 기존 engine-v4 실행 파일과 새 스크립트의 호환성, Electron 설정·저장·파일별 트랙 선택, 설치 프로그램 빌드를 검사한다.
- 합성 음성 결과는 실사용 영화의 전체 인식률을 뜻하지 않는다. 실제 영화 파일과 정답 자막이 제공되면 같은 평가 도구로 재현할 수 있게 한다.
- 화자 분리 모델, 새 엔진, 유료 클라우드 음성 인식 또는 생성형 대사 재작성은 이번 범위에 포함하지 않는다. 겹쳐 말하기·효과음에 가려진 대사는 여전히 오류가 생길 수 있다.
- 엄격한 억제는 불확실한 실제 대사도 빠질 수 있다. 누락이 문제인 파일은 '무음·효과음 억제: 기본'으로 다시 처리할 수 있다. 평가에서 전체 문자 오류율이 개선되었다고 주장하지 않는다.

## 공식 근거 (2026-10-29 확인)

- [faster-whisper](https://github.com/SYSTRAN/faster-whisper/blob/master/faster_whisper/transcribe.py): hotwords, compute_type, 단어 타임스탬프와 무음 관련 옵션.
- [OpenAI Whisper](https://github.com/openai/whisper/blob/main/whisper/transcribe.py): initial_prompt와 carry_initial_prompt, condition_on_previous_text의 반복 오류 관련 설명.
- [Silero VAD FAQ](https://github.com/snakers4/silero-vad/wiki/FAQ): 발화 임계값과 경계 설정은 실제 입력으로 검증해야 함.

## 구현·검증 결과

- Python 83개, Node 19개 회귀 테스트 통과. 기존 engine-v4에서 faster-whisper large-v3 및 OpenAI Whisper base 실행 확인.
- 실제 웃음소리에서 `ご視聴`가 출력되는 문제와 숨소리에서 불필요한 자막이 생성되는 문제를 재현했다. 12개 효과음 중 자막이 발생하던 2개가 0개로 감소. 이후 선택한 별도의 6개 효과음도 자막 0개.
- 일본어 대사 8개와 효과음 12개를 번갈아 배치한 145.9초 영상: 효과음·무음 구간 자막 겹침이 1.428초에서 0초로 감소. 이 샘플의 문자 오류는 65/174에서 66/174로, 엄격한 억제로 일부 실제 대사도 누락됐다.
- 일본어 대사만 긴 무음과 함께 배치한 영상: 문자 오류 42/174, 무음 겹침 0초로 변경 전후 동일. 영어 합성 대사 2종은 엄격한 검사 후 오류 38/740에서 56/740로 늘었다. 따라서 전체 인식 정확도 향상 수치로 홍보하지 않으며, 허위 대사 억제와 누락 사이의 선택을 설정에 표시했다.
- 실제 다중 음성 트랙과 중앙 채널 추출의 PCM 일치 확인. 일본어 트랙 선택 → 인식 → 한국어 번역 → 원문 보존·미리보기·별도 저장까지 Electron 앱에서 실행해 검증.
- 700×500 최소 창 크기에서 설정을 스크롤할 수 있고 작업 영역이 유지됨. 설치본에 포함된 Python/JavaScript 파일이 테스트한 소스와 일치하고 설치 파일의 SHA512가 업데이트 정보와 일치함.
- [평가 수치와 샘플 출처·해시](subtitle-evaluation-2026-10-29.json). 실제 영화 전체의 정확도나 모든 효과음의 완전 차단을 보장하는 결과는 아니다.
