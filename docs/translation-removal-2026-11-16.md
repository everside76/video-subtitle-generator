# 1.11.0 번역 기능 제거

사용자 요청에 따라 자막 번역 기능을 제거했다. 인식한 음성 언어의 SRT를 그대로 저장하며, 한국어 번역 또는 원문+한국어 모드를 제공하지 않는다.

## 제거 범위

- `main/translator.js`와 전용 테스트 파일 삭제. Google 번역 서버 호출, 요청 재시도, 번역 진행률, 원문 백업 생성 경로 제거.
- 음성 인식 완료 결과를 즉시 반환하도록 변경. 이전 클라이언트가 번역 옵션을 전달해도 처리하지 않음.
- 번역 선택 상자, 일본어 프리셋의 번역 설정, 원문/번역 전환 버튼 및 관련 상태·스타일 제거.
- 실행 시 저장된 `setting:translate-select` 설정 삭제. 원어 자막의 미리보기와 다른 이름으로 저장 기능 제공.
- 과거 버전의 변경 이력·검증 기록은 역사적 기록이며 현재 기능이 아님. 이미 생성된 사용자 SRT 파일은 삭제 대상이 아님.

## 검증

- Node 회귀 테스트 17개 통과: 일본어·영어·한국어 결과가 원래 언어 및 경로 그대로 완료되며, 과거 번역 옵션이 작동하지 않음을 포함.
- Electron에서 과거 번역 설정 자동 제거, 일본어 프리셋, 번역 컨트롤 제거, 실제 영어 인식·원어 미리보기·저장 일치 검사 통과. 번역 요청 0건 및 원문 백업 생성 0건.
- 기존 engine-v4로 완전 무음 처리 시 종료 코드 1과 무발화 안내, SRT 생성 없음 확인. Python 인식 로직은 변경하지 않았으며 이번에는 동결 엔진 실행으로 확인함.
- 설치 패키지에서 번역 모듈과 번역 UI가 없고 테스트한 소스와 일치함을 검사.
